# Job search

Use a verified company-to-board route and its existing adapter. Preserve provider job identity, canonical application URL, source date and date meaning, and scan observation times. A failed or incomplete board read must not close previously seen jobs.

Apply public multi-label categories independently of any person's search profile. Render the root README and category lists from the opening index; label ATS publication time separately from first discovery time. Keep the batch bounded and report board failures. Do not prepare or submit applications.
