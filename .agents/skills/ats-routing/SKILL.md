# ATS routing

Start with the official company careers page and its job or application links. Recognize provider host and board identity through the provider capability registry. Search the web only when the official route cannot be found or parsed, and confirm any result against the official company domain.

Reuse an already verified route unless a scheduled recheck or changed evidence requires inspection. For a confirmed new provider without a collector, the active AI task researches its public board, implements a reusable adapter, runs an isolated fixture test, and then activates the route and scans it. A bounded unsuccessful attempt records a concrete adapter failure. A script may record an AI work item but cannot claim to have performed that reasoning.
